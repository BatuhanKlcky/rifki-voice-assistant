# Rıfkı - Desktop Voice Assistant 🎙️

A personal desktop artificial intelligence assistant built with Python. This project serves as a hands-on experiment in capturing microphone audio, processing speech, and executing voice-controlled desktop tasks.

### 🛠️ Built With
* **Language:** Python
* **Audio Processing:** SpeechRecognition
* **Hardware Integration:** PyAudio

### 🚀 Features
* Captures real-time audio input via microphone
* Converts spoken language to text accurately
* Executes basic desktop commands based on recognized voice input
